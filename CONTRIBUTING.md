# Contributing to INCLINE

INCLINE is an unofficial fork of [Cline](https://github.com/cline/cline) and is maintained on a best-effort basis.
There is no obligation to provide support. Contributions are welcome under the [Code of Conduct](CODE_OF_CONDUCT.md).

- Build and environment notes: [DEVELOP.md](./DEVELOP.md)
- Implementation notes: `incline.md`
- Backlog: `task.md`

Please do not report problems with this fork to the upstream Cline project.
