# Security Policy

INCLINE is an unofficial fork of Cline and is maintained independently.
**Please do not report INCLINE issues to Cline Bot Inc.**

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository
(Security tab → "Report a vulnerability"). Please do not open a public issue
for security problems.

Include the affected version (`apps/vscode/package.json`), reproduction steps and impact.
This is a personal project, so responses are best-effort.

## Scope

Issues in INCLINE's own changes (throttling, Incline Tasks, ntfy integration,
data directory handling) are in scope. Vulnerabilities that exist in upstream
Cline should also be reported upstream following their policy.
